4M+ requests per day


When the same record arrives twice, processing both copies wastes time. I split our ingestion workflow into three stages so we could catch problems before passing work downstream.


Validate


I built multi-stage Apache Airflow DAGs with a dedicated validation step. Separating input checks from scheduling gives each stage a clear responsibility.


Deduplicate


Repeated input can consume capacity twice. A deduplication stage keeps repeated records from turning into repeated downstream work.


Schedule


Airflow coordinates when tasks run and how stages depend on each other. The resulting pipelines processed more than four million requests daily with 99.5% reliability.




+API crawler automation
~90% lower compute costs


A browser runs a whole page to reach its data. Many of our extraction workloads could retrieve the same underlying structured data through a REST service.


The change


I moved those crawlers to asynchronous REST services. While one request waited for a response, the service could get on with the next one.


The outcome


Once those crawlers were running as API services, we spent about 90% less on compute for that work.


Operating under load


I profiled container CPU and memory on Kubernetes and investigated queue deadlocks across our cloud workloads. Resolving those bottlenecks helped sustain 99.9% crawler uptime during peak loads.

Generate from the contract

Automating mobile API analysis
